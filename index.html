Sobre a StarCar Premium

A StarCar Premium é uma concessionária fictícia criada para gerenciamento de veículos através de um sistema web utilizando HTML, CSS, Bootstrap e JavaScript.

O sistema permite que administradores realizem cadastro, edição e exclusão de veículos, enquanto clientes podem visualizar o catálogo disponível.
